# GuardianHat IoT (Smart Hat)

An IoT-enabled smart safety helmet system designed for real-time monitoring, telemetry tracking, hazard alerts, and companion mobile application support.

## Project Structure

```
GuardianHat-IoT/
├── .gitignore
├── README.md
├── firmware/
│   └── README.md
└── mobile_app/
    └── README.md
```

## Modules

- **[firmware/](firmware/README.md)**: Embedded firmware for onboard sensors, Wi-Fi/cellular connectivity, MQTT telemetry, and alert dispatch.
- **[mobile_app/](mobile_app/README.md)**: Companion mobile application for telemetry visualization, live status, notifications, and device configuration.
